# Example Results

This directory contains a small curated subset of result figures from a
Sangamon simulated experiment. They are intended for documentation and project
presentation only.

Included assets:

- `sangamon_hydrograph_assimilation.gif`: hydrograph ensemble evolution across
  EKI iterations at a representative outlet gauge.
- `sangamon_final_cr_map.png`: final calibrated runoff coefficient map.
- `sangamon_hydrograph_metric_map.png`: spatial hydrograph performance summary.
- `sangamon_total_rainfall_map.png`: total rainfall forcing map.
- `sangamon_parameter_cr_division_0_mean_std.png`: parameter convergence trace.

Full experiment outputs should be regenerated locally or published as release
assets.
